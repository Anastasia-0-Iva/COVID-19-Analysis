# Проект — COVID-19 Analysis

COVID-19 Analysis — это проект, предназначенный для анализа и визуализации данных о заболеваемости COVID-19 в различных городах и в разные годы. Проект использует библиотеку `pandas` для обработки CSV-файлов с данными, что позволяет выявлять тенденции, сравнивать показатели и проводить исследования на основе реальной статистики.

## Основные возможности

Проект позволяет выполнять следующие задачи:

-   **Загрузка и обработка данных:** Чтение CSV-файлов с данными о заболеваемости COVID-19, включая информацию о городах, датах, количестве случаев, смертях и выздоровлениях.
-   **Анализ данных:** Расчет статистических показателей, выявление закономерностей и тенденций в распространении вируса.
-   **Сравнение показателей:** Анализ заболеваемости по разным городам и временным периодам.

## Технические детали и зависимости

*   **Язык:** Python
*   **Основные библиотеки:**
    *   `pandas` (для обработки и анализа данных)
*   **Формат данных:** CSV

## Начало работы

Для использования проекта тебе потребуется выполнить следующие шаги:

1.  **Получение данных:**
    *   Убедитесь, что у Вас есть CSV-файл с данными о заболеваемости COVID-19.
    *   Формат файла должен включать колонки, которые ожидает скрипт.

2.  **Клонирование репозитория:**
    Выполните в консоли:

**Для Windows:**
```
git clone git@github.com:Anastasia-0-Iva/COVID-19-Analysis.git
cd COVID-19_Analysis
python -m venv venv
.\venv\Scripts\activate
poetry install
```

**Для Linux/macOS:**
```
git clone git@github.com:Anastasia-0-Iva/COVID-19-Analysis.git
cd COVID-19_Analysis
python3 -m venv venv
source venv/bin/activate
poetry install

```

3.  **Подготовка данных:**
    *   Если ты добавишь пример файла, укажи его путь.
